# Google Labs Stitch UI & Design Rules

1. **Design System Tokens**:
   - Reference `DESIGN.md` for consistent color palettes, typography, spacing, and component definitions.
2. **Component Modularity**:
   - Write reusable, self-contained React/frontend components with clear property interfaces.
3. **Accessibility**:
   - Verify keyboard navigation, ARIA semantics, and contrast compliance according to WCAG standards.
